<h1> AI Interview Coach</h1>

<p><strong> Overview </strong></p>
An application that helps users prepare for job interviews.

<p><strong> Features: </strong></p>

-Role selection<br>
-Question generation<br>
-Answer feedback<br>

<p><Strong> Installation </Strong></p>
1. Download or clone the repository.<br>
2. Open the project folder.<br>
3. Open index.html in a web browser.<br>


<p><strong> Usage: </strong></p>
  
1.Select role<br>
2.Generate question<br>
3.Enter answer<br>
4.Review feedback<br>
5.Repeat for additional practice if needed.<br>
