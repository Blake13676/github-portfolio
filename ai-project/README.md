<h1> Study Question Generator </h1>

<p><strong> Description </strong></p>
The Study Question Generator is a Python application that creates practice questions based on a topic entered by the user.

<p><strong> Technologies Used </strong></p>

Python<br>
Microsoft Copilot<br>

<p><strong> Features </strong></p>

Users enter a study topic.<br>
Program generates practice questions.<br>
Helps students review course material.<br>

<p><strong> What I Learned </strong></p>
This project helped me practice Python programming, user input handling, and conditional statements. It also demonstrated how AI tools can assist with software development and project planning.<br>
